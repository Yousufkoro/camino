# 0.29 — Check revisions against the whole draft

A quoted phrase is not evidence that a proposed criticism is valid. The care/work benchmark exposed that distinction: the reviewer asked for challenges and outcomes that the following sentences already explained.

When revisions exist, Camino now runs a second, focused Workers AI check against the full essay, exact prompt, supplied requirements and activities. This check must identify a concrete unanswered question. Already-covered criticism is removed only when the answering quote matches the essay. Concrete enrichment is labeled optional and lowered in priority. Generic, missing, duplicate, malformed or unavailable assessments remain visibly uncertain instead of confirmed weaknesses. Empty revision lists skip this extra call.

The second check uses the same disclosed provider and consented draft; it excludes coursework and does not persist the request. It can add latency. Admission-forecast guards also inspect its output before rendering. This is an additional AI check, not independent proof of semantic correctness.

Validation: regression fixture from the synthetic care/work failure; whole-draft removal, optional/vague/duplicate/missing-response boundaries, provider failure, empty-list bypass, data minimization and second-pass outcome-claim rejection; full regression suite and desktop/mobile UI checks. Live model findings are recorded in deployment state after release.
