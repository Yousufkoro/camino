# 0.17 — Infinite Path and Living Compass

Replaces the hero's library illustration with two original Three.js experiences. Infinite Path is the default; the selector persists locally. Branching luminous tubes grow into the distance with traveling light and cursor response. The dimensional compass searches with varying speed, then eases toward a deterministic visual angle only when completed quiz history and an actual saved direction exist. Angles do not represent college locations.

Preserves the headline, navigation, CTAs and three interactive theme cards. Corrects headline contrast. Uses existing local Three.js, one rendering loop, offscreen/tab pause, disposal, mobile geometry reductions and static reduced-motion/WebGL fallback. No student profile or result copies are stored.

Verification: pure state/determinism/motion tests; full validation suite; Chromium WebGL screenshots at 1440 and 390px, tablet state/persistence/lifecycle checks. Software-rendered browser checks do not certify physical-device GPU performance.
