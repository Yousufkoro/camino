# 0.45 — Full native import/export flow and stable calendars

A saved application checkpoint's calendar UID included its position in the list; inserting an earlier reminder changed existing event identities on the next export. Generate deterministic IDs from event identity instead of array index or export time. Personal milestone exports use the same generator, while retaining their explicit personal/unverified description. Calendar-client reimport behavior varies; stable IDs improve matching but do not guarantee how an external calendar handles repeated imports.

Fold ICS physical lines to75 UTF-8 octets without splitting Unicode characters, escape backslashes/newlines/commas/semicolons, reject impossible calendar dates and preserve all-day date semantics without inventing closing times or alarms. Include published/annual/entered provenance in sourced calendar descriptions. The saved-checkpoint UI now shows its actual date basis instead of calling every sourced date user-entered.

Reproducible full-flow browser script: scripts/browser-import-export.cjs. It uses an isolated browser, synthetic native PDF and mocked standalone account APIs, never model inference. Profile selection→actual file upload→explicit issuer/credit confirmation→three saved courses/15credits→plan PNG→sourced checkpoint save/reload→ICS download→add earlier reminder→verify existing UID stability. Test dates and any synthetic inserted reminder are QA inputs, not recommendations for that profile. Cross-campus course equivalencies are not assumed by this test.

The existing live reader matrix also passed all10 native/wrapped/two-column/scanned/image/TXT fixtures, including OCR, semester guard and custom-school recovery. No finite fixture set certifies all student PDFs. Full native flow runs at1440/390/320; unit tests cover ICS byte folding, Unicode, stable IDs, escaping and leap/invalid dates. Full validation and post-deployment browser checks accompany this release. Five-feature scope remains; AI reviewer quality/timing and physical/cross-browser coverage remain incomplete.
